# v0.1.0 release-promotion record

`v0.1.0` is a stable-release promotion from the certified and published
`v0.1.0-alpha.2` baseline. The promotion changes product-version metadata
only; it does not change DockerMap runtime behavior, deployment wiring, or its
security model.

The existing alpha tag and prerelease are immutable historical evidence. The
stable release must be certified and tagged from its own exact source SHA and
its own tag-build image evidence. A scan or maintainer decision for an earlier
image digest does not automatically apply to that new image.

## Unchanged support and product boundaries

- The certified profile remains the three-service Docker-only deployment.
- Native/full-host deployment is not supported or certified.
- DockerMap remains a read-only inspection product; it does not change observed
  Docker state.
- This release is not a certification for production public-internet exposure.
- Atlas remains bounded and opt-in, rather than the default product surface.
- Continuous Docker events, resource telemetry, and temporal repeated-event
  findings are not shipped.

Use the exact-candidate release gates and evidence requirements in the release
documentation before creating `v0.1.0`. This record does not authorize tagging
or publication.
